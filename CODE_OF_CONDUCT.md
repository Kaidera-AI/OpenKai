# Code of Conduct

OpenKai follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith. Harassment, personal attacks, and bad-faith disruption are not tolerated. Project maintainers may remove, edit, or reject comments, commits, code, issues, and other contributions that violate this code, and will communicate reasons for moderation decisions when appropriate.

Report conduct issues to the maintainers via GitHub (open a private security advisory if sensitive, or contact the repository owner). All reports are reviewed and investigated.

The full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/ — enforcement guidelines: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
