# A2 — keyless TUI boot on a clean host (kos-test, Rocky Linux 10.2, 2026-09-04)

```
$ timeout 12 script -qec "openkai" /dev/null > ~/e024/tui.log   # no provider keys, no models.yml, fresh ~/.omp
tui exit=124 (still running at the 12 s timeout) bytes=502164
$ <strip ANSI> ~/e024/tui.log | grep -i "openkai|kaidera|welcome|login|settings|model"
             OpenKai v0.1.12    engine 18.0.11
                                  Welcome back!
 Tip: Press Ctrl+R to reuse a message you wrote before.
           Select provider to login
$ ls -d ~/.omp ~/.openkai
/home/rocky/.omp  /home/rocky/.openkai     (created by the boot; agent.db, history.db, cache)
```

Observed: the binary boots without any key, paints the OpenKai header with the engine line, and opens the in-TUI **provider sign-in** wizard instead of exiting to the shell — the keyless-boot contract (standing goal 5) holds on Linux. **PASS.** Nit for W3: the welcome banner says "Welcome back!" on a first run.
