## Addendum 2 — the `embed` entry of /workers/health during a 20 s stop

```
$ GET /workers/health (embed key, worker stopped)
{'embed': {'ok': False, 'status_code': 502, 'error': 'worker unavailable: [Errno -2] Name or service not known'}}
$ GET /degradation
{"degraded":[]}
$ /workers/health embed key (worker restarted)
{'embed': {'ok': False, 'status_code': 502, 'error': 'worker unavailable: '}}
```

Result: **FAIL for the fail-loud promise** — a stopped embed worker never appears on `GET /degradation` (0 s, 75 s, and 20 s windows), while writes are accepted and the admin backlog counter grows; `/workers/health` is the only surface that notices. OpenKai's `/memory stats` reads `/degradation` and therefore reported "none" during the outage. Two REWORK items: Cortex — degradation must cover a down embed worker / growing backlog; OpenKai W3 — read `/workers/health` (and the admin backlog when the token is present) into `/memory stats` and the status line.
